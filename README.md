# Priority-Based-To-Do-List-Project-DSA
A menu-driven C program for managing tasks with priority levels, allowing users to add, display, complete, and delete tasks.

**Priority-Based To-Do List in C:~**

A simple console-based Priority-Based To-Do List application developed in C as a Data Structures and Algorithms mini project. The program allows users to add, display, complete, and delete tasks while assigning priorities to help manage daily activities efficiently.

*Features:-*

- Add Tasks: Add tasks with a description and priority.
- Display Tasks: View all tasks along with their IDs, priorities, and completion status.
- Complete Tasks: Mark tasks as completed using their task ID.
- Delete Tasks: Remove tasks from the list.
- Priority Management: Organize tasks according to High, Medium, and Low priority levels.
- Input Validation: Handles invalid inputs and menu choices.
- Menu-Driven Interface: Easy-to-use command-line interface.

*Technologies Used:-*

- Programming Language: C
- Libraries: "stdio.h", "string.h"
- Data Structures: Structures and arrays
- IDE: Visual Studio

*Project Purpose:-*

This project was created to explore the fundamentals of C programming and Data Structures through the development of a practical task-management application. It demonstrates the use of structures, functions, arrays, input handling, and basic task-management logic.
